# 抓包教程

> 本文档记录松下智能家电云接口（app.psmartcloud.com）的抓包方法，供各品类协议逆向参考。洗衣机/烘护机的状态与控制协议即按此路线实机验证（2026-11）。

## 1.1 抓包路线选择

| 路线 | 可行性 | 说明 |
| --- | --- | --- |
| 手机 App + 证书代理 | ❌ 基本不可行 | Android 7+ 的 App 不信任用户安装的 CA 证书，无 root 抓不到明文；iOS 可尝试 Stream 等工具（未实测） |
| **官方 web 控制台 + 浏览器 DevTools** | ✅ 推荐 | 松下官方网页控制台与 App 走**同一套云接口**，浏览器里直接抓，零环境成本 |
| mitmproxy 系统代理 | ✅ 可选 | 适合批量保存、过滤分析；web 控制台场景下与 DevTools 等价 |

## 1.2 方法一：web 控制台 + DevTools（推荐）

前置条件：注册「松下智能家电」App 账号并绑定设备。

### 第 1 步：登录并生成控制台链接

云端没有公开的控制台入口，链接要自己拼：先调登录接口拿 `ssId`，再按设备拼 URL。用下面的脚本（`pip install requests`）：

```python
# -*- coding: utf-8 -*-
"""松下智能家电：登录并生成 web 控制台链接。"""
import hashlib
import urllib.parse

import requests
import urllib3

urllib3.disable_warnings()  # 云端自签名证书

HOST = "https://app.psmartcloud.com/App/"
PHONE = "你的App手机号"
PASSWORD = "你的App密码"

s = requests.Session()
s.verify = False

_msg_id = 100

def nid():
    global _msg_id
    _msg_id += 1
    return _msg_id

def post(url, payload, xtoken=None):
    headers = {"User-Agent": "SmartApp", "Content-Type": "application/json"}
    if xtoken:
        headers["xtoken"] = xtoken
    return s.post(url, json=payload, headers=headers, timeout=20).json()

# 1. UsrGetToken
data = post(HOST + "UsrGetToken",
            {"id": nid(), "uiVersion": 4.0, "params": {"usrId": PHONE}})
token_start = data["results"]["token"]

# 2. 密码 MD5 链（全大写）
pwd_md5 = hashlib.md5(PASSWORD.encode()).hexdigest().upper()
inter_md5 = hashlib.md5((pwd_md5 + PHONE).encode()).hexdigest().upper()
final = hashlib.md5((inter_md5 + token_start).encode()).hexdigest().upper()

# 3. UsrLogin → ssId
data = post(HOST + "UsrLogin",
            {"id": nid(), "uiVersion": 4.0,
             "params": {"telId": "00:00:00:00:00:00", "checkFailCount": 0,
                        "usrId": PHONE, "pwd": final}})
res = data["results"]
usr_id, ssid = res["usrId"], res["ssId"]
print(f"登录成功 usrId={usr_id} ssId={ssid}")

# 4. 设备列表
data = post(HOST + "UsrGetBindDevInfo",
            {"id": nid(), "uiVersion": 4.0, "params": {"usrId": usr_id}},
            xtoken=f"SSID={ssid}")
devs = data["results"].get("devList", [])
print(f"共 {len(devs)} 台设备：")

# 5. 拼 web 控制台 URL
# 已知 subType 映射：洗衣机 32 / 烘护机 29；其他品类留空后逐个尝试
SUBTYPE = {"0600": "32", "0610": "29"}
for d in devs:
    did = d["deviceId"]                 # 格式：MAC_品类_后缀
    category = did.split("_")[1]        # 品类号，如 0600
    subtype = SUBTYPE.get(category, "")
    model = d.get("deviceMNO") or d.get("deviceType") or ""   # 型号，必填
    name = urllib.parse.quote(d.get("deviceName", ""))
    url = (f"https://app.psmartcloud.com/ca/cn/{category}/{subtype}/index.html"
           f"?deviceId={did}&devType={model}&usrId={usr_id}"
           f"&SSID={ssid}&deviceName={name}")
    print(f"\n{d.get('deviceName', did)}（品类 {category}）：\n  {url}")
```

### 第 2 步：打开控制台

把打印出的链接粘到 Chrome（⚠️ URL 里的 `SSID` 携带登录会话，**勿外传**）：

- 证书警告「不安全」：云端是**自签名证书**，点「高级 → 继续前往」即可
- 正常会看到设备控制面板（与 App 控制页同款布局）

### 第 3 步：抓包

1. `F12` 打开 DevTools → **Network** 面板
1. 筛选框输入 `WDev`（状态/控制接口都以 WDev 开头）
1. 在控制台页面上操作设备（改参数、启动、暂停……），每一步操作对应一条 `WDevSetStatusInfoCommon` 请求
1. 点开请求查看 **Payload**（请求体）与 **Response**（响应体），记录下来

## 1.3 方法二：mitmproxy（批量分析）

需要把多个请求存下来批量比对时用 mitmproxy：

```bash
pip install mitmproxy
mitmdump --set ssl_insecure=true        # 监听 127.0.0.1:8080，跳过自签证书校验
```

浏览器/系统代理指向 `127.0.0.1:8080` 后，正常走方法一的流程，请求自动落盘（flows 文件）。

- **App 抓包**：只有 iOS 可行（安装并信任 mitmproxy CA 即可）；Android 7+ 的 App 不信任用户证书，无 root 设备抓不到，不建议在这条路上耗时间
- flows 文件可用 `mitmproxy`、`mitmproxy2swagger` 等工具回放分析

## 1.4 关键坑位（实机验证）

1. **`devType` 必须填**：URL 里 `devType` 留空会导致控制台 JS 崩溃（卡加载/白屏，控制台报 `washerBase` 未定义）。取值 = 设备列表的 `deviceMNO` 字段（如 `XQG100-L188`、`FDC-L1026D`）
1. **远程控制键**：设备机身「远程控制」键（云端字段 `remoteStatus`）未开启时，云端**拒绝所有控制指令**（控制台自动跳「远程控制未开启」警告页）。先按一下机身「远程控制」键使其常亮；状态读取不受此限
1. **自签名证书**：云端证书为松下自签（`*.psmartcloud.com`，有效期 2016–2116），所有客户端必须跳过校验（`verify=False` / Chrome 手动放行 / `ssl_insecure`）
1. **单点登录**：同一账号后登录者会挤掉先登录者的会话（App ↔ 控制台 ↔ HA 互挤），抓包期间 App 掉线属正常
1. **大小写敏感**：设备 token 计算中 MAC 与品类大写、后缀**保持原始大小写**，否则鉴权失败

## 1.5 协议速查

- **登录链**：`UsrGetToken` → `md5(md5(md5(密码)+手机号)+token)` 全大写 → `UsrLogin` → `ssId`
- **设备 token**：`sha512( sha512(MAC后6位_品类_MAC前6位) + "_" + 后缀 )`
- **状态**：`POST WDevGetStatusInfoBD158`，header `xtoken: SSID=<ssId>`，body `{id, usrId, deviceId, token}`
- **控制**：`POST WDevSetStatusInfoCommon`，body `{id, usrId, deviceId, token, params:{...}}`
  - `params` 是**快照式**：洗衣机 47 字段 / 烘护机 49 字段，下发时只改目标字段、其余带当前值
  - 响应 `{"results": {"todoId": N}}`，`todoId` 按设备独立递增
  - 启动命令：快照基础上加 `runingStatus:1 + startType:1 + smartCloudProgram:0`
- **状态字段 → 控制字段**：状态接口用 `xxxCur`/`xxxOrg` 区分当前值与设定值，控制参数用设定值；个别字段（如 `powerStatus`）状态接口没有，靠本地缓存兜底
